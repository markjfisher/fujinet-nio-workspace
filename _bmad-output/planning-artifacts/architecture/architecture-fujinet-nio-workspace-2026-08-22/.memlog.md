- (direction) Fast path: user asked to ratify and summarize for method/work-item tracking. Spine is the only deliverable.
- (decision) AD-1 layered broker: clients and fujinet-disk.device call fujinet-nio-lib; only Amiga fn_transport names fujinet-nio.device; backends own physical transport. Prevents apps/disk from OpenDevice(serial.device) or the broker.
- (decision) AD-2 broker is service-agnostic: payloads are opaque FujiBus bytes. Prevents DiskService/FileService parsing in the broker.
- (decision) AD-3 public ABI is backend-neutral: FujiNetNIORequest has no serial/Zorro/framing fields; one command FUJINET_NIO_CMD_EXCHANGE. Prevents backend leak into callers.
- (decision) AD-4 two error domains: io_Error Exec-only (exec/errors.h symbols, no numeric literals); fn_nio_error FN-only. Abort: IOERR_ABORTED + FN_ERR_ABORTED (0x13). Never copy FN into io_Error. Prevents conflating Exec and FujiNet results.
- (decision) AD-5 one FujiNetNIORequest per transport context, at most one in-flight exchange; no machine-global IORequest across independent tasks. Disk device owns its own context; CLI may be process-local singleton. Prevents recreating the serial race in the shim.
- (decision) AD-6 single FIFO worker; each EXCHANGE is atomic send-then-receive; broker serializes distinct IORequests, not two tasks sharing one request. Prevents interleaved frames on one wire.
- (decision) AD-7 backend lazy-open keep-open; reopen allowed after backend_close on expunge or fatal reset. Open-once is steady-state not a lifetime ban. OpenCnt 0 does not close backend. Prevents dual reopen paths and forbids recovery.
- (decision) AD-8 expunge deferred/refused while opens or queued/in-progress requests remain. Prevents unload racing live IORequests.
- (decision) AD-9 BeginIO: clear IOF_QUICK before any ReplyMsg; failed paths fn_response_length=0; DoIO io_Error!=0 maps to local/device failure never stale fn_nio_error. Prevents IOF_QUICK double-complete and garbage lengths.
- (decision) AD-10 migration: Stage 1 blocks Stage 2; Stage 2 tests isolated from serial-direct shim; Stage 3 is fn_transport cut-over off serial.device; Stage 4 removes disk idle-close. Prevents dual OpenDevice(serial.device) and skipped ABI.
- (decision) AD-11 second backend via Option A: separate broker binaries identical public ABI. Prevents loadable-backend ABI until coexistence without reboot is required.
- (decision) AD-12 before Stage 2, remove fn_internal.h from fn_session.c so broker may compile framing by path with no library-symbol cycle.
- (decision) AD-13 environment loads DEVS:fujinet-nio.device; lib does not autoload. Missing broker OpenFAIL maps to FN_ERR_NOT_FOUND, not serial-busy.
- (constraint) FN_ERR_ABORTED 0x13 unused in current fujinet-nio.h; must not collide with 0xFF FN_ERR_UNKNOWN. Not yet in the header (Stage 1).

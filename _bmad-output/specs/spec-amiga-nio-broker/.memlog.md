- (decision) Express distill from product brief + nio-broker-architecture.md + backlog/nio-broker.md; no architecture redesign.
- (decision) Slug amiga-nio-broker. Architecture is adopted companion (ABI/layout owner). Brief and backlog absorbed into kernel + stages/requirements companions.
- (constraint) fujinet-nio.device is the backend-neutral, service-agnostic broker; selected backend is sole owner of the physical FujiNet transport.
- (constraint) Applications and fujinet-disk.device go only through fujinet-nio-lib; only the Amiga transport shim OpenDevice the broker.
- (constraint) One broker request is one atomic request/response; concurrent Amiga tasks are serialized by the broker FIFO worker.
- (constraint) Exec io_Error and FN-space errors stay separate; never copy FN codes into io_Error.
- (constraint) Serial is the first backend only; future Zorro/floppy/packet-native backends use the same public broker ABI.
- (constraint) Abort: io_Error=IOERR_ABORTED, fn_nio_error=FN_ERR_ABORTED (0x13); fn_response_length=0; one ReplyMsg.
- (constraint) Recovery: lazy-open keep-open; reopen after backend_close on expunge or fatal reset; OpenCnt 0 does not close backend; client CloseDevice is not backend_close.
- (constraint) One IORequest per transport context; no machine-global IORequest across independent tasks.
- (constraint) Stage 1 blocks Stage 2; Stage 2 tests isolated from serial-direct shim; Stage 3 cut-over; Stage 4 idle-close removal; Stage 5 future backend binary.
- (capability) CAP-1: Publish broker public ABI and FN_ERR_ABORTED; framing compiles into broker without fn_internal.h.
- (capability) CAP-2: Concurrent callers get atomic serialized exchanges via one FIFO worker.
- (capability) CAP-3: Two-domain BeginIO/completion errors per architecture §2.1 matrix.
- (capability) CAP-4: AbortIO queued and in-progress without double-reply or remote rollback.
- (capability) CAP-5: Backend exclusive ownership, lazy-open, recovery, expunge-while-busy invariant.
- (capability) CAP-6: Transport shim becomes broker client; disk and apps unchanged at cut-over.
- (capability) CAP-7: Isolated Stage 2 broker test suite against real serial backend.
- (capability) CAP-8: Environment loads broker before any fn_transport_init; lib does not auto-load.
- (capability) CAP-9: Disk device idle-close removed; transport close only on explicit teardown.
- (capability) CAP-10: Future backend is a new broker binary, same public ABI, same higher-level tests.
- (question) Which exec/errors.h symbol is used for generic invalid-request (nonzero flags/pad, NULL+nonzero)? Stage 2; do not invent a numeric.
- (question) Concrete C signatures for backend_open/close/exchange remain Stage 2.
- (question) Numeric exchange timeout and serial baud/unit/timer are backend-private; not specified in this spec.
- (question) fn_struct_size grow-with-defaults policy is named only when the ABI actually grows; until then exact-match reject.
- (question) Expunge drain/abort sequence beyond refuse-while-busy is Stage 2 detail.
- (assumption) Amiga FN_MAX_PACKET_SIZE oversize bound is 1024 (fn_protocol.h non-cc65); architecture prose saying 512 is aligned at Stage 1, not a different policy.
- (assumption) Near-term Option A (one compiled-in backend per broker binary); Option B out of this spec.
- (note) HDF/RDB, loadable-backend Option B, and implementing Zorro itself are non-goals of this spec.

- (decision) Malformed broker IORequest: io_Error = appropriate native Exec/device request-validation error; fn_nio_error = FN_ERR_INVALID. Actual symbol from exec/errors.h source-check at Stage 1/2. Never bake guessed numerics into tests. Not an open architectural decision.
- (decision) Initial backend C API: uint8_t backend_open(void); void backend_close(void); uint8_t backend_exchange(const uint8_t *request, uint16_t request_len, uint8_t *response, uint16_t response_capacity, uint16_t *response_len). No broker objects. Stage 2 may add a private ctx pointer without changing semantics. Multi-adapter later.
- (decision) backend_open returns FN_OK or FN_* setup/transport error. backend_close is idempotent/safe when already closed and fully resets framing/session. backend_exchange is one atomic transaction while open; sets *response_len=0 before work; never retains caller buffers.
- (decision) Broker spec does not name baud/unit/timer/timeout values. backend_exchange must terminate in bounded time and return FN_ERR_TIMEOUT when the selected backend deadline is exceeded. Serial owns named constants/config privately.
- (decision) fn_struct_size v1: exact sizeof(FujiNetNIORequest). Future prefix compatibility: too-small-for-min-prefix reject; known older size accept with documented defaults on missing tail; caller size > driver-known size reject. Old caller to newer broker may work; new caller to older broker rejects. Compatibility table implemented only when struct grows.
- (decision) Expunge v1: refuse/defer if OpenCnt!=0 or queue nonempty or exchange in progress; else stop worker, close backend if open, release resources. Ordinary expunge does not abort or destroy live requests. Follow Exec delayed-expunge conventions at Stage 2.
- (decision) Length fields are UWORD (ABI capacity 65535). Oversize vs platform FN_MAX_PACKET_SIZE, currently 1024 on Amiga. ABI does not hard-code 1024. Architecture prose 512 is stale and is corrected in the architecture companion.

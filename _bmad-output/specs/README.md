# Active BMad specs

This directory holds **in-progress** spec kernels (`spec-{slug}/`).
`bmad-spec` and `bmad-build` look here.

When every story in a spec is `done` and the workspace goal is accepted,
move the whole folder to `../completed-specs/` so it stays readable but is
no longer treated as an active contract.

Do not mix these with `completed/` at the workspace root — that archive is
for `backlog/` goal files.

- (decision) INTB_RBF is an exclusive Exec interrupt handler installed with SetIntVector, not an interrupt-server chain entry. Exec scratch for that handler is D0, D1, A0, A1, A5, A6; all other registers must be preserved. Project policy: FujiNet handler uses only D0-D1/A0-A1 as scratch and does not require A5/A6. Replace 'interrupt-server boundary' with 'RBF interrupt-handler boundary'.
- (constraint) On first open, acquire built-in serial hardware through misc.resource (including MR_SERIALPORT and required serial-control resources) before changing SERPER, serial interrupt enables, or INTB_RBF. If those resources are already owned, fail OpenDevice cleanly with no Paula or interrupt-state change. Exclusive open of fujinet-serial.device does not substitute for misc.resource.
- (constraint) On final close: stop new ownership transitions; resolve/cancel any retained READ once; mask RBF; handle pending receive state with SERDATR-before-ack; restore previous INTB_RBF handler and relevant RBF interrupt-enable state; release acquired misc.resource resources exactly once; then finish CloseDevice. No ISR-visible IORequest or device-private pointer may remain after vector removal. Do not expunge, rename, patch, or steal Kickstart serial.device.
- (constraint) Preserve and restore the previous INTB_RBF handler and relevant previous RBF interrupt-enable state. Do not claim to preserve or restore SERPER: it is write-only and cannot be read back. Successful close must not depend on reconstructing a prior baud divisor.
- (constraint) Every serviced RBF event follows exactly: read SERDATR, record received byte and status, then clear INTF_RBF once. Never clear RBF before sampling SERDATR. Never use the rejected duplicate-INTREQ/NOP acknowledgement. Same order for pending-RBF during rearm or teardown.
- (decision) Keep quiesced-after-FLUSH: exchange completes, FLUSH, RBF quiesced; next WRITE/READ/QUERY rearms RBF before the first new request byte is written to SERDAT. Rearm while an RBF condition is already pending must sample SERDATR and retain byte/status before clearing the pending interrupt. Always-armed receive remains a documented PiStorm fallback if leading response bytes are lost or rearm latency is unacceptable.
- (decision) CMD_READ waits until the requested byte count is available (stock-like pending READ). QUERY-then-immediate-READ is rejected. Resolves the earlier open question on READ contract.
- (decision) PiStorm is the sole hardware-stability acceptance gate (CAP-5). A real 68000 return-to-Shell is not required before 38400 is called done for this spec. Resolves the earlier hardware-gate open question.
- (decision) Pending CMD_READ is an explicit ownership state machine: NEW -> PENDING; from PENDING either RBF-driven COMPLETING or AbortIO/FLUSH/Close ABORTING; both end at REPLIED. Exactly one path may transition a pending READ out of PENDING and exactly one ReplyMsg may occur. Protect the transition with Disable()/Enable() or equivalent so ISR and task-level AbortIO cannot both complete the same request.
- (decision) If a pending READ exists when CMD_FLUSH is issued, transition it through the same single-owner cancellation path as AbortIO, complete it with IOERR_ABORTED, then clear the software receive queue and quiesce RBF. FLUSH must not leave a retained IORequest pointer referring to discarded queue state. FLUSH retains Paula/misc.resource ownership.
- (constraint) Keep distinct private latches hardware_overrun_latched (Paula SERDATR overrun) and software_ring_overflow_latched (private receive ring had no free slot). Public QUERY/status may collapse both into the existing overrun indication. Expose the private distinction to host/native test state where practical.
- (constraint) SETPARAMS accepted range remains 300-230400 for ABI compatibility. FujiNet hardware acceptance matrix is 9600/19200/38400 only. Do not extend that matrix without asking. Accepted SETPARAMS rates are not implied to be interrupt-validated on real hardware.
- (assumption) ESP pacing 16/2000 remains the product default; this spec does not require turning pacing off to pass CAP-5.
